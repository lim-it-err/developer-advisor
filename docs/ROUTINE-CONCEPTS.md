# 데일리 루틴 컨셉 카탈로그 — "CS와 세상을 넓게 보기"

> 데일리 루틴을 미니게임들의 회전 덱으로 만들기 위한 컨셉 풀.
> 지향: 컴퓨터 공학 × 세상 읽기의 궁합. 사용자 애정 분야: 항공 사고 × CS, 세상의 의사판단 × CS.
> 상태: 🎯 착수 확정 · 💡 후보

## 메타 구조

- 🎯 **1. 「나의 작은 개발자」 시즌제** (프린세스메이커형) — 루틴/미니게임 결과가 4스탯(👁 안목 · 🗣 언어화 · 🧭 판단 · 📚 교양)으로 적립. 4주 시즌 종료 시 스탯 조합으로 엔딩(아키텍트/장인/제너럴리스트/…, 히든: 「번아웃」 — 매일 3칸 꽉 채우면 도달하는 역설 엔딩). 육성 대상은 캐릭터가 아니라 학습자 본인. 기존 결말 분기의 시즌 스케일 버전.

## 세상 × CS 시리즈 (요일 테마 재료)

- 🎯 **2. ✈️ 블랙박스의 날** — 항공 사고 = CS 사례연구. 737 MAX MCAS(단일 센서 = SPOF), AF447(모드 혼동 = 상태 기계 UI), 테네리페(통신 모호성 = API 계약), KAL801+CRM(주니어가 반론하는 리뷰 문화), 허드슨강(체크리스트 vs 판단). 브리핑 → "소프트웨어적 교훈" 서술.
- 💡 **3. ⚖️ 판단의 날** — CS 밖 의사결정을 CS 개념으로: 트리아지(우선순위 큐·기아), 금리(지연 피드백 제어), 쿠바 미사일 위기(데드락·백오프), D-Day(롤백 불가 배포의 리스크 윈도우). 선택 → 실제 결과 대조.
- 💡 **4. ⏳ 타임머신 결정** — 역사적 기술 결정 재연: JS 10일 탄생, 32비트 유닉스 시간, 넷스케이프 재작성. 선택 → 30년 뒤 청구서.
- 💡 **5. 📖 독서의 날** — 비개발서 챕터 브리핑 + CS 연결: 총균쇠=경로 의존성, 카너먼=캐시 vs 연산, 전장의 안개=관측가능성.
- 💡 **6. 🏛 오늘의 재판** — 기술 논쟁 법정극. 양측 변론 읽고 판결문 작성 (논증형 설명 훈련).

## 미니게임 (2~10분 스낵)

- 💡 **7. 🃏 머지 or 반려** — 코드/설계 카드 스와이프 판정 + 콤보.
- 🎯 **8. 🕵️ 사건 파일** — 장애 포스트모템 추리 연속극. 매일 단서 1개(로그→그래프→배포 이력), 최종일 근본 원인 지목. 연속극 구조 = 데일리 리텐션 장치.
- 💡 **9. 🔧 한 줄의 날** — 역사를 바꾼 한 줄 diff(하트블리드, 단위 오류). 두 문장 해설 쓰기.
- 💡 **10. 📉 차트 읽기** — 모니터링 그래프 진단 쓰기 (SRE의 눈).
- 💡 **11. 🎲 주사위 아키텍트** — 무작위 제약 3개 뽑고 설계 스케치.

## 역할극

- 💡 **12. 🎭 배역의 날** — 같은 장애를 CS상담원/CTO/기자 배역으로 각각 글쓰기.
- 💡 **13. 🧭 트롤리의 날** — 엔지니어링 윤리 딜레마, 논거 작성 → 평판형 피드백.
- 💡 **14. 🗺 지도 밖 산책** — 도메인 풀 랜덤 카드 5분 브리핑 + 꼬리 질문 (최소 부담).
- 💡 **15. 🎬 시사회의 날** — 영화 장면의 시스템 독해 (기존 오마주 미션 예고편 겸용).

## 착수 순서 (사용자 피드백 반영, 2026-08-03 확정)

1. **12. 배역의 날** — 사용자 1픽. 기존 미션 인프라 재사용(새 유형 '배역극': 장애 타임라인 = legacyFiles, 배역 3글 = 제출물). 즉시 착수.
2. **5. 독서의 날** + **15. 시사회의 날** — 카드 데이터로 통합 제작(책/영화 카드), UI는 루틴 슬롯에 연결.
3. **1. 시즌제 스탯** — 우산 구조. 프론트 큐 소화 후.
4. **8. 사건 파일** — 연속극 1편(5일).
5. **2. 블랙박스의 날** — 기확정 유지(항공×CS는 배역극·독서 카드 소재로도 침투).

보류: **13. 트롤리의 날** (사용자: "너무 흔함" — 동의, 차별화 각 나오면 재론), **14. 지도 밖 산책** (전달이 잘 안 됨 — 매일 도메인 풀 무작위 카드 1장의 5분 브리핑+꼬리 질문, 최소 부담 상식 슬롯. 재설명 후 반응 보고 재론).

## 설계 원칙

- 루틴은 고정 3슬롯이 아니라 **컨셉 덱의 회전**: 요일 테마 + 시즌 이벤트 + 랜덤 카드.
- 모든 컨셉은 기존 장치(결말 분기·히든 퀘스트·평판·감성 원칙)와 호환되게.
- 사실 기반 원칙: 사고 사례·역사 결정은 공적 기록만, 중립 서술, 희생자 존중 (블랙박스의 날은 특히 — 유머 금지 구역).
