# 데일리 루틴 컨셉 카탈로그 — "CS와 세상을 넓게 보기"

> 지향: 컴퓨터 공학 × 세상 읽기의 궁합. 사용자 애정 분야: 항공 사고 × CS, 세상의 의사판단 × CS.
> 상태: 🎯 착수 확정 · 💡 후보

## 메타 구조

- 🎯 **1. 「나의 작은 개발자」 시즌제** (프린세스메이커형) — 루틴/미니게임 결과가 4스탯(👁 안목 · 🗣 언어화 · 🧭 판단 · 📚 교양)으로 적립. 4주 시즌 종료 시 스탯 조합으로 엔딩(아키텍트/장인/제너럴리스트/…, 히든: 「번아웃」 — 매일 3칸 꽉 채우면 도달하는 역설 엔딩). 육성 대상은 캐릭터가 아니라 학습자 본인. 기존 결말 분기의 시즌 스케일 버전.

## 세상 × CS 시리즈 (요일 테마 재료)

- 🎯 **2. ✈️ 블랙박스의 날** — 항공 사고 = CS 사례연구. 737 MAX MCAS(단일 센서 = SPOF), AF447(모드 혼동 = 상태 기계 UI), 테네리페(통신 모호성 = API 계약), KAL801+CRM(주니어가 반론하는 리뷰 문화), 허드슨강(체크리스트 vs 판단). 브리핑 → "소프트웨어적 교훈" 서술.
- 💡 **3. ⚖️ 판단의 날** — CS 밖 의사결정을 CS 개념으로: 트리아지(우선순위 큐·기아), 금리(지연 피드백 제어), 쿠바 미사일 위기(데드락·백오프), D-Day(롤백 불가 배포의 리스크 윈도우). 선택 → 실제 결과 대조.
- 💡 **4. ⏳ 타임머신 결정** — 역사적 기술 결정 재연: JS 10일 탄생, 32비트 유닉스 시간, 넷스케이프 재작성. 선택 → 30년 뒤 청구서.
- 💡 **5. 📖 독서의 날** — 비개발서 챕터 브리핑 + CS 연결: 총균쇠=경로 의존성, 카너먼=캐시 vs 연산, 전장의 안개=관측가능성.
- 💡 **6. 🏛 오늘의 재판** — 기술 논쟁 법정극. 양측 변론 읽고 판결문 작성 (논증형 설명 훈련).

## Codex 자문 반영 (2026-08-03, outbox/001)

Codex가 기존안 3개를 비평했다. 판정(사용자 + Claude):

- **5. 독서의 날 — 현행 유지.** Codex: "일대일 비유는 장식적, 반례 경계를 찾게 하라." 사용자: "오전 재미 용도라 반대." 판정: 아침 슬롯의 역할은 훈련이 아니라 **점화**다 — 무거운 훈련은 미션이 담당한다. 다만 Codex의 통찰은 공짜로 가져온다: 카드의 꼬리 질문 일부를 "이 비유가 깨지는 곳은 어디인가?"로 낸다. UI·채점 추가 없이 톤으로만 반영.
- **7. 머지 or 반려 — 경량 채택.** 판정 스와이프 + **근거 토큰 1탭**(정확성/계약/운영/가독성/지금은 아님), 총 2탭 상한. 가끔 정답이 "질문 없이는 판정 불가"인 카드 포함(질문 창·평판 철학과 연결). 근거 다양성 콤보 같은 복잡 규칙은 기각 — 사용자: "너무 많은 조작은 이탈로 이어진다."
- **11. 주사위 아키텍트 — 데일리로는 보류, 「운영 청구서」 메커니즘은 채택.** Codex의 2라운드(설계 스케치 → 청구서 카드: "삭제 요청 10만 건", "한 리전 단절")는 이 답변에서 가장 좋은 아이디어다 — 선택의 결과가 돌아온다는 우리의 결말 분기 DNA와 정확히 같다. 단 아침 루틴에는 무겁다. **주말 몰입 슬롯 또는 새 미션 유형 '설계 청구서'**로 흡수한다(평가: 제약 추적성·되돌리기 비용·포기한 품질의 명시 — 루브릭화 가능).

Codex 신규 12개 중 눈에 띄는 것 (착수 순서엔 아직 미편입):
- **✈️ MEL 디스패처** — graceful degradation을 "어떤 능력을 잃었는가"로 모델링. 항공×CS 최애 크로스오버 정면.
- **🧳 가방은 지금 어디에** — 뒤섞인 이벤트 원장, "모름을 계약에 포함". S5 수하물 세계관 재사용 가능.
- **🌙 인수인계 압축** — 다음 라운드에 자기가 남긴 문서만 보고 대응. 언어화 훈련과 게임의 결합이 정확함.
- **⚡ 블랙 스타트 순서표** — 의존성 복구. "전부 재시작은 전략이 아니다."
- 보너스의 **AI 코드 위험 패턴 5개**(@Transactional 자가호출, 비멱등 재시도, 폴백 정상화, 엔티티 equals, LocalDateTime)는 코드 판독 미션 백로그로 직행 — 특히 1번은 S3 프록시 경계, 학습자 약점(인터페이스)과 정면으로 맞닿는다.

## 설계 원칙

- 루틴은 고정 3슬롯이 아니라 **컨셉 덱의 회전**: 요일 테마 + 시즌 이벤트 + 랜덤 카드.
- 모든 컨셉은 기존 장치(결말 분기·히든 퀘스트·평판·감성 원칙)와 호환되게.
- 사실 기반 원칙: 사고 사례·역사 결정은 공적 기록만, 중립 서술, 희생자 존중 (블랙박스의 날은 특히 — 유머 금지 구역).
