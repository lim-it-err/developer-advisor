# 002 — 평일 노코드 미니게임 공동 기획

사용자 지시가 왔다: **평일 루틴에서 코드 작성·긴 타이핑을 빼고, 미니게임·판단류로 채워라.**
주말은 코딩(프로젝트) 유지. 참고로 읽을 것: docs/TASTE.md, docs/ROUTINE-CONCEPTS.md(신규 후보 4개 추가됨),
현재 라이브 게임: 머지 or 반려(스와이프+근거 토큰), 사건 파일 연속극, 카드 갈래 질문.

## 질문 1 — 새 미니게임 컨셉
평일 슬롯(2~10분, 모바일 1~3탭, 타이핑 0)에 맞는 **새 미니게임 5개 이상**을 제안하라.
- 조건: 기존 게임·ROUTINE-CONCEPTS의 19개와 겹치지 않는 "다른 동사"일 것. 각각 메커니즘/CS 연결/한계 순으로.
- 우리 취향(TASTE §2): 판정·예측·순서·자원배분 같은 **판단의 동사**를 좋아한다. 채점보다 결과 공개(시나리오)가 남는 방식.

## 질문 2 — Claude의 신규 4개 비평
ROUTINE-CONCEPTS에 방금 추가된 16~19번(트리아지 아침, 어느 쪽이 터졌을까, 그래프 문진, 타임머신 결정 승격)을
비평하라 — 약한 것은 약하다고. 각각 "평일 슬롯감인가"를 판정하라.

## 질문 3 — 요일 슬롯 맵 검토
아래 초안(dev-014 예정)에 구멍이 있으면 지적하라:
- 월 수사: 사건 파일 단서 / 스와이프 5장 / 카드 갈래
- 화 판정: 판독·설계리뷰 읽기 / 결말 예측 1건 / 스와이프 5장
- 수 교양: 독서 카드+갈래 / 설명 시작 칩만 고르기(문장 완성은 선택) / 사건 파일 단서
- 목 기획자: 회의 질문 칩 3개 던지기 / 검토 대상 읽기 / 카드 갈래
- 금 회고: 이번 주 리뷰 다시 읽기 / 스와이프 5장 / 설명 훈련(주중 유일 타이핑, 선택 표기)
