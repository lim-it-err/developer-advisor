# 001 — 데일리 루틴 컨셉 아이디어 (신규 10개 이상 + 기존안 비평)

## 맥락 (참조 파일을 지금 새로 읽을 것)

- `docs/ROUTINE-CONCEPTS.md` — 우리가 이미 낸 15개 컨셉. **이것과 겹치지 않는 것만** 내라.
- `docs/CURRICULUM.md` — 제품 철학 (특히 유머·감성 원칙, 히든 케이스, 결말 분기).
- 제품: 3년차 비IT 도메인 Java 개발자의 학습 앱. 데일리 루틴을 미니게임 덱으로 만드는 중.

## 사용자 취향

- 컴퓨터 공학 × 세상 넓게 보기의 궁합. 특히 ✈️ 항공 사고 × CS, CS 밖 세상의 의사판단 × CS.
- 게임 형식 선호: 육성+엔딩(프린세스메이커), 연속극, 미니게임.
- 유머는 도메인에서 나온 건조한 것만. 실제 사고·희생자 소재는 존중 우선.

## 질문

1. **신규 루틴/미니게임 컨셉 10개 이상** — 위 15개와 겹치지 않게. 각각: 이름 / 메커니즘(어떻게 노는가) / CS 연결고리 / 한계나 리스크 1줄.
2. **우리 15개 중 약한 것 3개 지적** — 왜 약한지, 살리려면 어떻게 고칠지.
3. **보너스**: 10분 남으면 — "AI가 짠 코드 리뷰하기" 미션 유형에서, 학습자를 속이기 좋은 '그럴듯하지만 위험한 코드'의 패턴 5개.
