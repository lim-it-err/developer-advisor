# dev-014 — 평일 루틴 노코드 재편 (기존 콘텐츠만 사용)

## 배경
사용자 지시: 평일에는 코드 작성·필수 타이핑을 넣지 않는다. 게임·판단류로 채운다. 주말 프로젝트 코딩은 유지.
**주의: inbox/002에 대한 자문 답변(outbox/002-answer.md)이 있으면 먼저 읽고, 질문 3의 지적을 반영해도 된다 — 반영 시 보고서에 명시.**

## 사양 — 요일 슬롯 맵 (모두 기존 기능·링크 재사용, 신규 게임 개발 없음)
- **월 「수사의 월요일」**: 🚆 사건 파일 오늘 단서(진행 중인 케이스, 없으면 1편 Day1 링크) / 🍜 머지 or 반려 / 🌙 카드 갈래 1장(오늘의 카드 링크, 갈래 선택까지가 체크)
- **화 「판정의 화요일」**: 🚆 판독·설계 리뷰 미션 읽기(현행 유지) / 🍜 결말 예측 1건(미예측 미션 1개 시드 선택 → 미션 페이지 결말 섹션 링크) / 🌙 머지 or 반려
- **수 「교양의 수요일」**: 🚆 독서 카드+갈래(현행 카드 슬롯 유지) / 🍜 사건 파일 단서 / 🌙 설명 시작 칩 고르기(칩 선택까지가 체크 — 문장 완성은 선택 사항으로 라벨)
- **목 「기획자의 목요일」**: 🚆 기획자 브리핑 읽기(현행) / 🍜 회의에서 질문 칩 3개 던지기(meetingChats 메시지 수로 done 판정) / 🌙 카드 갈래 1장
- **금 「회고의 금요일」**: 🚆 이번 주 리뷰 다시 읽기(현행) / 🍜 머지 or 반려 / 🌙 설명 훈련 — 라벨에 "(선택·주중 유일 타이핑)" 명시, done 판정은 현행
- **주말**: 현행 유지 (시사회 카드 + 프로젝트 소미션 코딩)
