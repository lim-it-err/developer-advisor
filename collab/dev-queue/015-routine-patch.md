# dev-015 — 루틴 패치 (outbox/002 지적 ①②④⑤⑥ 반영)

## 배경
자문 002의 요일 맵 구멍 지적을 반영한다. ROUTINE-CONCEPTS "자문 반영 2차" 절 참조.

## 사양
1. **사건 파일 일일 배너**: 진행 중(시작했고 미지목) 사건이 있으면 RoutinePage 상단에 작은 보조 배너 "🕵️ 수사 진행 중 — Day n 단서 열기" 상시 노출(요일 무관). 슬롯 아님, 분모에 안 들어감.
2. **회의 질문 칩 즉시 전송**: PlannerMeetingPanel 칩 탭 = 즉시 전송(입력창 경유 제거). 목요일 점심 done 판정을 메시지 3개 → **1개**로 완화.
3. **갈래 완료 날짜**: `cardForkChoiceDates: { [cardId]: 'YYYY-MM-DD' }` 추가, 루틴 갈래 슬롯 done은 "오늘 선택한 갈래 존재"로 판정. 과거에 이미 고른 카드가 배정되면 그 카드의 "다시 읽었어요" 수동 체크 허용(manualCheckable 폴백).
4. **읽기 슬롯 딥링크**: 화요일 읽기는 미션 브리핑 탭 앵커로, 금요일 회고는 최신 리뷰 1건(#리뷰 페이지 해당 버전)으로 바로 연결. 문서 전체 랜딩 금지.
5. 스와이프 화요일 저녁 교체는 **이번 범위 아님** (신규 게임 20번이 생긴 뒤 별도).

## 검증 게이트
- vitest·playwright·vite build 그린. 특성화 테스트: 목요일 done=질문1, 갈래 당일 판정, 진행 중 사건 배너 노출/비노출.

## 범위 밖
