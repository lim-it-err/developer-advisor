# dev-005 — 「머지 or 반려」 스와이프 미니게임 (엔진+UI)

## 목표
코드 카드 판정 미니게임의 **엔진과 UI만** 구현한다. 카드 콘텐츠는 Claude 전담 — `data/sampleSwipeCards.js`가 아직 없으면 **스키마에 맞는 임시 카드 2장을 컴포넌트 내부 상수로** 넣고 보고서에 명시(파일 생성 금지).

## 카드 스키마 (동결 계약)
```js
{ id, title, code /* 짧은 Java 스니펫 */, correct: 'merge'|'reject'|'question',
  reasonTokens: ['정확성','계약','운영','가독성','지금은 아님'], correctToken, explain /* 판정 해설 2~3문장 */ }
```

## 사양 (합의된 게임 규칙 — outbox/001 비평 반영판)
1. `/routine/swipe` 페이지. 카드 1장: 코드 + 제목. 조작은 **최대 2탭**: ① 판정 3버튼(✅ 머지 / ❌ 반려 / ❓ 질문 필요) ② 판정 후 근거 토큰 5개 중 1탭.
2. 정답이 'question'인 카드 존재 — "질문 없이는 판정 불가"가 정답인 경우.
3. 판정+토큰 후 해설 공개 → 다음 카드. 세션은 5장, 끝나면 요약(맞은 판정 수/근거 적중 수). 복잡한 콤보 규칙 없음(단순 연속 정답 스트릭만).
4. 결과는 localStorage 저장 불필요(세션 요약만). 스와이프 제스처는 선택 구현 — 버튼이 기본.

## 검증 게이트
- `npx vite build` 그린, 375px에서 가로 스크롤 없음, 콘솔 에러 0

## 범위 밖
- `data/` 파일 생성·수정 금지. 카드 문구는 임시 표시임을 UI에 밝힐 것("샘플 카드").
- 루틴 요일 빌더에 끼워 넣지 말 것 (연결은 이후 우리가).
