# dev-016 — 「한 번만 물어본다면」 가설·관측 게임 (엔진+UI)

## 목표
outbox/002에서 합의된 신규 게임 1호. `data/sampleProbeRounds.js`(3판, 스키마 주석 포함 — 이미 존재, 문구 수정 금지)를 플레이 가능하게.

## 플레이 흐름 (탭 3번)
1. `/games/probe` — 오늘의 라운드 1판(날짜 시드). 상황 + 가설 3개 표시.
2. **관측 선택(1탭)**: probes 3개 중 하나 → `result` 공개. 선택 후 변경 불가 ("관측은 한 번뿐").
3. **가설 지목(1탭)**: hypotheses 중 하나 → 판정 공개: 적중 여부, `resolution`, 그리고 **정보량 해설** — 내가 고른 관측의 `infoNote` + `bestProbeKey`와 비교("최선의 관측은 ○○였습니다"). 다른 관측들의 infoNote도 접이식으로 열람 가능.
4. `eliminates`를 UI에 활용: 관측 결과 공개 시 배제된 가설을 시각적으로 흐리게(취소선 아님, 흐림 — 지목은 여전히 자유).

## 사양
- 진행 저장: `probeSessions: { [date]: { roundId, probeKey, verdictKey } }` — 하루 1판, 재플레이는 다음 날(과거 라운드 열람은 자유, 판정은 당일 1회).
- 시즌 스탯: 지목 시 판단 +2, `bestProbeKey` 선택 시 안목 +1 (중복 방지 기존 규칙).
- `/games` 바로 플레이에 추가. 375px 기준, E2E 1개(관측→흐림→지목→해설).
- 이후 dev-015의 방향과 일관되게: 화요일 저녁 슬롯 교체는 **별도 티켓**에서 (이번 범위 아님).
